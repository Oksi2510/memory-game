# Memory Game

Memory Game is a browser game where the goal is to find all matching pairs of cards.

The goal is to find all 8 pairs using as few moves and as little time as possible.

## Features

* 16 cards (8 pairs)
* Random card shuffling
* Ability to open two cards at a time
* Automatic closing of unmatched pairs
* Move counter
* Game timer
* Victory modal
* New Game button
* Responsive layout

## Technologies

* JavaScript
* HTML
* CSS
* ES Modules
* LocalStorage

## How to Run Locally

1. Clone the repository:

   `git clone https://github.com/Oksi2510/memory-game.git`

2. Open the project folder:

   `cd memory-game`

3. Start the project using a local development server.

4. Open the local URL provided by the development server in your browser.

For example, you can use the Live Server extension in Visual Studio Code.
